# Contributing

Thanks for helping young explorers learn about space. Please open an issue before large changes, keep pull requests focused, and use Conventional Commit messages such as `feat: add moon phase lesson` or `fix: preserve offline mission progress`.

## Development

1. Use Node.js 22 or newer.
2. Run `npm install`.
3. Run `npm run dev`.
4. Before opening a pull request, run `npm run lint`, `npm test`, and `npm run build`.

Add tests for game rules and keep educational content grounded in cited primary sources. Do not use NASA insignia or suggest NASA sponsors or endorses this community project. Keep accessible names, visible focus, and keyboard interaction in new UI.
